# 商店圖片資料夾（直接用同名檔案替換即可）

## 怎麼換圖？

1. 找到下面表格裡的檔名，做一張**同名**的 PNG（透明背景最好），丟進對應資料夾，覆蓋舊檔。
2. 瀏覽器按 **Ctrl+F5**（手機：重新整理）就會看到新圖。不用改任何程式。
3. 尺寸盡量照表格的比例（可以更大更清楚，不要變形）。比例不同，圖會被壓扁或拉長。
4. 想要動畫：做 GIF，把檔名改成 `.png`（例如 `idle.gif` 改成 `idle.png`），瀏覽器照樣會動。
5. 圖片不見或檔名打錯，程式會自動改用內建的向量圖，不會壞掉。

## 資料夾地圖

| 資料夾 | 放什麼 | 檔名 |
|---|---|---|
| `heroes/角色id/` | 全新角色的 6 種動作 | `idle`（站著）、`run-right`（往右跑）、`run-left`（往左跑）、`attack`（答對攻擊）、`hurt`（答錯受傷）、`lose`（倒下） |
| `gear/` | 配件（披風、服裝、帽子、眼鏡、表情氣泡） | `配件id.png` |
| `decor/` | 房間飾品（掛畫、地毯、寵物、植物…） | `飾品id.png` |
| `themes/` | 小屋背景（牆壁＋地板） | `主題id.png`，尺寸 1600×814 |

> 角色圖建議 340×360（或 2 倍 680×720）；六張動作圖請用同樣大小、腳底對齊畫面底部，換動作時才不會跳來跳去。
